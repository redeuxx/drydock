{# Hook settings, shared by the add form and the hook page (superadmins only). #} {% macro hook_fields(form, prefix, hosts) -%}

Admins attach the hook to jobs by this name.

Leave empty for a container hook: it runs only for container jobs on this host whose target is exactly the container below (a name, or an ID if the job uses one). Set a Compose project for a stack job's hook: the container below is then a service or container name of that project.

A JSON array: the program and its arguments, passed as they are with no shell, so $(...), ${...} and quotes are not interpreted. Docker cannot stop a command that outlives its timeout; wrap long commands in timeout. Write dumps to a file, not to standard output, for example ["timeout", "250", "pg_dump", "-U", "postgres", "-f", "/var/lib/postgresql/data/dump.sql", "app"].

Name, uid, name:group or uid:gid. Empty: the container's own user.

An absolute path inside the container. Empty: the container's own.

Run logs are visible to every role that can see runs, viewers included. When off, drydock logs only how many bytes the hook wrote and, if it fails, the last 4 KiB of its standard error.

Post-hooks run even when a pre-hook or the backup failed, so they must be safe to run when the pre-hooks did not all finish.
